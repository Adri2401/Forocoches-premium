# ForoCoches Premium

Script para ForoCoches: modo oscuro en negro puro, bloqueo de anuncios, lista negra, hilos ocultos y favoritos, y nick Premium.

## Instalación

1. **Instala Tampermonkey**
   - **En el ordenador:** en cualquier navegador (Chrome, Firefox, Edge, Opera, Safari…), desde [tampermonkey.net](https://www.tampermonkey.net/).
   - **En el móvil:** usa **Firefox** e instala el complemento Tampermonkey desde el menú de Firefox → *Complementos*.
2. **Copia este enlace y pégalo en la barra de direcciones del navegador:**

   ```
   https://raw.githubusercontent.com/Adri2401/Forocoches-premium/main/forocoches-premium.user.js
   ```

3. Se abrirá Tampermonkey con el script. Pulsa **Instalar**.

## Actualizaciones automáticas

Activa las actualizaciones automáticas para recibir siempre la última versión sin hacer nada:

1. Abre el panel de Tampermonkey → **Configuración**.
2. En la sección de actualización de scripts, elige cada cuánto buscar actualizaciones (por ejemplo, **Cada día**).
3. Comprueba también que en el script, en su pestaña **Configuración**, está marcada la opción **Buscar actualizaciones**.

Si quieres actualizar en el momento, en el panel de Tampermonkey pulsa **Buscar actualizaciones**.

> `forocoches-oled.user.js` es el enlace antiguo: solo sirve para que las instalaciones viejas se pasen solas al nuevo. No hace falta tocarlo.
